# Akrielle User Flows

Version: 1.0

---

# Overview

This document defines how users interact with Akrielle from the moment they enter the website until they receive personalized beauty recommendations.

The objective is to make every interaction feel effortless, premium, and trustworthy.

# Error Flow

No Face Detected

↓

Ask user to upload another image.

---

Multiple Faces

↓

Ask user to upload a photo containing only one person.

---

Poor Lighting

↓

Suggest taking another photo in natural lighting.

---

Image Too Small

↓

Suggest uploading a higher resolution image.
