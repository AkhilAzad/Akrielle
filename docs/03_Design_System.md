Inspirations:

- Apple
- Dior
- Rare Beauty
- Glossier
- Linear
- Stripe

Design Principles

- Elegant

- Premium
- Modern
- Clean

Avoid:

- Bright neon colors
- Cartoon graphics
- Heavy shadows
- Cluttered layouts
